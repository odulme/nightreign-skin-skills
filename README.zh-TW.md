# Nightreign Skin Skills

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [日本語](README.ja.md)

一個 Claude Code 技能，用來為《艾爾登法環：黑夜君臨》(ELDEN RING NIGHTREIGN) 製作離線服裝（造型）MOD：從參考圖或現成模型出發，做出在實際遊玩中站得住腳的服裝；可選做可切換的表情、遊戲內選單，以及能裝進任何 me3 整合包的安裝程式。它以在遊戲裡驗證過的做法為基礎，標明哪些只做過離線測試，效果粗糙的地方也會直說。裡面每一條經驗，都是一套在 Blender 裡好看、進了遊戲就出問題的服裝換來的。

> 非官方粉絲專案。與 FromSoftware、萬代南夢宮（Bandai Namco）、Anthropic 皆無關聯，也未獲其認可。

## 技能內容

| 技能 | 涵蓋範圍 |
|---|---|
| `nightreign-skin` | 完整的服裝流程，共十個階段（S0-S9），每個階段都有出口關卡：從參考圖定下視覺、用 Tripo 生成 AI 基礎模型、在 Blender 裡整理成一整塊連續的身體、綁到角色原版骨架並用真實動作檢查、FLVER 匯出規範與各個索引表、材質與貼圖通道、平面表情臉卡（以及如何去掉舊臉殘留的光暈）、獨立新服裝的參數鏈、可選的原生外掛（表情切換、次級擺動、NPC 選單、連線同步、影格時間的教訓）、遊戲內驗收，以及「安裝時合併」的發布安裝程式。另附第二條路線：移植現成的 PMX / FBX / VRM 模型。 |

它建立在 **`nightreign-modding`** 之上（me3 設定檔與載入順序、開發版疊加包、Smithbox 與 regulation 儲存格修改、WitchyBND、參數配方、隱私掃描、證據標籤），這個技能發布在配套儲存庫 [Nightreign Boss Skills](https://github.com/odulme/nightreign-boss-skills) 裡。兩個都要安裝。

文中的結論都附有證據標籤（`[game-MP]`、`[game]`、`[code]`、`[data]`、`[sim]`、`[inferred]`），可以分辨哪些是在遊戲裡親眼看到的，哪些只是離線測試或推論。引擎相關的事實是在黑夜君臨 1.3.3.0 上查到的，遊戲更新後請重新確認。技能正文為英文，描述為中英雙語，所以用哪種語言提問都能觸發。

## 完整案例：哈基蝸

哈基蝸（Hajiwo）是復仇者的一套獨立迷因服裝：大腦袋、小身體，臉上印的表情會隨情況變化。技能從四張迷因圖一路跟到發布：

1. 參考板和三視圖，由製作者本人確認；
2. 一次 Tripo 多視角生成；
3. Blender 整理——第一版綁定用的是剛性「布偶分件」，進遊戲後看得到斷面和兩層袖子，被否決了；最終採‌​⁠‍‌‌​⁠‌‌​⁠​‍⁠‌​⁠​‍​⁠​​​⁠​‍​⁠‌‍​⁠​‌​⁠​‌​⁠​‍​⁠​‌​‍⁠‌‌‍​⁠​⁠​​​⁠‌‌​⁠‍‌‌‍​‌​⁠​⁠‌‍‌‍‌‍​‍用一整塊連續的身體；
4. 遊戲檔案和獨立的新服裝項目，原版外觀仍然可以選；
5. 在固定範本上畫平面表情，再投影到臉卡上（最後共 15 張臉）；
6. 一個原生外掛：依情況換臉（平時、受傷、殘血、倒地、施放絕招、發呆、重擊），讓頭紗擺動，並依設計在連線時把每個人的選擇同步給隊友（完整的雙機測試尚未進行）；
7. 由圓桌廳堂壁爐前的一位 NPC 提供的表情選單；
8. 一個安裝程式，把服裝合併進玩家正在使用的任何 me3 整合包。

案例裡也記下了被否決的路線和踩過的坑（每影格耗時 20 毫秒的外掛、引擎根本沒有驅動的骨骼、me3 檔案重新導向造成的「整合包已更新」誤報），因為時間主要花在這些地方。

另有一個較短的案例——把某個二次元遊戲角色的模型移植到隱士身上——用來說明現成模型路線。它能進遊戲遊玩，但武器握持、物理和部分材質仍然粗糙，技能裡如實寫明。

## 新手從哪裡開始

1. 先從遊戲封包裡解出原版檔案（用 `nightreign-modding` 裡的解包工具）。
2. 裝好 me3，用獨立存檔建立一個開發版設定檔。
3. 只改參數：在 Smithbox 裡照著原版複製一套服裝的參數鏈（Goods → CharaInit → Protector → 商店項目 + 文字），並把該角色的 parts 檔案複製成新的模型編號，直到遊戲裡的衣櫃出現新項目。
4. 只改貼圖，而且只改這份副本（絕不改原版檔案）：用 WitchyBND 解包，改顏色，再打包回去。
5. 換模型：在 Blender 裡學綁骨和權重，綁到該角色的原版骨架上，匯出成 FLVER。
6. 表情、物理和外掛放到最後，它們最費工夫。

如果使用能執行腳本的代理（裝了這些技能的 Claude Code），每一步就是一句請求；技能會要求代理在安裝任何東西之前，先把證據拿給你看。

## 鐵則：只移植已發售的遊戲

技能以強制執行的**第 0 步**開頭。從其他遊戲移植任何模型、貼圖、動作、特效或音效之前，Claude 必須：

1. 上網搜尋核實：來源遊戲（或包含該內容的 DLC、更新）已經正式公開發售、可以購買，並記下證據；
2. 如果遊戲、DLC 或角色尚未發售，素材來自外洩、未發布版本的資料挖掘或測試版，或者無法確認發售狀態，就**拒絕**移植；
3. 閱讀模型本身的使用條款——許多角色模型禁止用於其他遊‌​⁠‍‌‌​⁠‌‌​⁠​‍⁠‌​⁠​‍​⁠​​​⁠​‍​⁠‌‍​⁠​‌​⁠​‌​⁠​‍​⁠​‌​‍⁠‌‌‍​⁠​⁠​​​⁠‌‌​⁠‍‌‌‍​‌​⁠​⁠‌‍‌‍‌‍​‍戲的 MOD 和二次散布，能公開下載不代表已獲授權。

用自己的設計做服裝、用自己的參考圖生成 AI 基礎模型（參考圖畫的是其他遊戲角色時除外）、修改黑夜君臨自己的服裝，都不需要這項檢查。用作參考的社群作品（迷因圖、同人圖）屬於原作者：請標示並致謝，不要把他們的圖放進發布內容。如果你 fork 或改編本技能，請保留這條規則。

## 需要什麼

- 支援技能的 **Claude Code**，並開啟網路搜尋（第 0 步需要）。
- PC 版 **ELDEN RING NIGHTREIGN**（你自己購買的正版）。
- **me3**（0.10.1 或更新）、**Smithbox**、**WitchyBND**、**Blender** 4.x、**texconv**（DirectXTex）。
- 依路線而定：**Tripo**（帳號與點數；MCP 服務或 CLI）以及畫表情用的圖像生成模型；想讓代理操作正在開啟的 Blender 場景時用 **BlenderMCP**；小工具需要 **SoulsFormats** 加 .NET Framework 的 C# 編譯器；**FLVER Editor**（支援黑夜君臨的分支）；PMX 模型用 **mmd_tools**；輔助腳本需要帶 Pillow 和 NumPy 的 **Python** 3；只有測試連線時才需要 **Seamless Co-op**。

## 安裝

把技能資料夾複製到 Claude Code 的技能目錄，同時裝上 Nightreign Boss Skills 裡的 `nightreign-modding`：

```
git clone https://github.com/odulme/nightreign-skin-skills
git clone https://github.com/odulme/nightreign-boss-skills
mkdir -p ~/.claude/skills
cp -r nightreign-skin-skills/skills/nightreign-skin ~/.claude/skills/
cp -r nightreign-boss-skills/skills/nightreign-modding ~/.claude/skills/
```

- 個人技能（所有專案可用）：`~/.claude/skills/`（Windows 上是 `%USERPROFILE%\.claude\skills\`）。
- 專案技能（只在一個專案裡用）：`<你的專案>/.claude/skills/`。

安裝後開一個新的 Claude Code 工作階段。問到黑夜君臨服裝或造型時，技能會依描述自動載入；也可以直接點名（「用 nightreign-skin」）。這些檔案都是一般的 Markdown，也可以當教學直接閱讀。
