# Nightreign Skin Skills

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **日本語**

『ELDEN RING NIGHTREIGN』（エルデンリング ナイトレイン）の衣装（スキン）をオフライン MOD として作るための Claude Code スキルです。参考画像や既存のモデルから出発して、実際のプレイに耐える衣装に仕上げます。差し替え可能な表情、ゲーム内メニュー、どの me3 パックにも入れられるインストーラーも、必要に応じて扱います。ゲーム内で通用した方法を土台に、オフラインでしか試していない部分はそう明記し、粗さが残った部分もはっきり書いています。ここにある教訓はどれも、Blender では正しく見えてゲームでは崩れた衣装と引き換えに得たものです。

> 非公式のファンプロジェクトです。FromSoftware、バンダイナムコエンターテインメント、Anthropic とは一切関係がなく、承認も受けていません。

## スキルの内容

| スキル | 対象 |
|---|---|
| `nightreign-skin` | 衣装制作の全工程を 10 段階（S0〜S9）にまとめ、段階ごとに完了条件を設けています。参考画像からのビジュアルの確定、Tripo による AI ベースメッシュの生成、Blender で一続きの体に整える作業、キャラクターのバニラ骨格へのバインドと実際のモーションでの確認、FLVER の書き出し規約と各インデックス表、マテリアルとテクスチャのチャンネル構成、平面の表情を貼るフェイスカード（古い顔のハロー除去を含む）、独立した新衣装のパラメータ連鎖、任意のネイティブプラグイン（表情切り替え、揺れもの、NPC メニュー、マルチプレイ同期、フレーム時間の教訓）、ゲーム内での受け入れ確認、そして「インストール時に合成する」配布用インストーラーまで。既存の PMX / FBX / VRM モデルを移植する第二のルートも収録しています。 |

土台として **`nightreign-modding`**（me3 プロファイルと読み込み順、開発用オーバーレイ、Smithbox と regulation のセル編集、WitchyBND、パラメータの作り方、プライバシースキャン、証拠ラベル）を使います。これは姉妹リポジトリ [Nightreign Boss Skills](https://github.com/odulme/nightreign-boss-skills) で公開しています。両方をインストールしてください。

記述には証拠ラベル（`[game-MP]`、`[game]`、`[code]`、`[data]`、`[sim]`、`[inferred]`）を付けており、ゲーム内で実際に確認したことと、オフラインのテストや推論にとどまることを区別できます。エンジンに関する事実はナイトレイン 1.3.3.0 で調べたものです。アップデート後は確認し直してください。スキル本文は英語、説明文は中国語と英語なので、どちらの言語で質問しても読み込まれます。

## 実例：ハジウォ

ハジウォ（哈基蜗 / Hajiwo）は、復讐者用の独立したミーム衣装です。大きな頭に小さな体、顔に印刷された表情が状況に応じて変わります。スキルは 4 枚のミーム画像からリリースまでを追っています。

1. 参考ボードと三面図（制作者本人が確認）。
2. Tripo によるマルチビュー生成 1 回。
3. Blender での整理。最初のリグは硬い「人形パーツ」方式で、ゲーム内で切断面や二重の袖が見えて却下され‌​⁠‍‌‌​⁠‌‌​⁠​‍⁠‌​⁠​‍​⁠​​​⁠​‍​⁠‌‍​⁠​‌​⁠​‌​⁠​‍​⁠​‌​‍⁠‌‌‍​⁠​⁠​​​⁠‌‌​⁠‍‌‌‍​‌​⁠​⁠‌‍‌‍‌‍​‍ました。採用されたのは一続きの体です。
4. ゲームファイルと独立した新しい衣装項目。バニラの見た目もそのまま選べます。
5. 固定テンプレートの上に平面の表情を描き、フェイスカードに投影（最終的に 15 種類の顔）。
6. 状況（通常、被弾、瀕死、ダウン、アーツ、放置、強攻撃）に応じて顔を切り替え、ベールを揺らし、マルチプレイでは各プレイヤーの選択を共有するよう設計されたネイティブプラグイン（2 台での完全なテストはまだです）。
7. 円卓の暖炉の前に立つ NPC が提供する表情メニュー。
8. プレイヤーが使っているどの me3 パックにも衣装を合成するインストーラー。

却下したルートや踏んだ落とし穴（1 フレームに 20 ミリ秒かかるプラグイン、エンジンが一度も動かしていなかった骨、me3 のファイルリダイレクトが原因の「パックが更新された」誤検知）も記録しています。時間がかかったのはまさにそこだからです。

もう一つ、短い事例として、あるアニメ調ゲームのキャラクターモデルを隠者に移植したケースで既存モデルのルートを説明しています。プレイはできましたが、武器の持ち方、物理、一部のマテリアルは粗いままで、スキルにもそう書いています。

## 初めての人へ

1. ゲームのアーカイブからバニラのファイルを取り出す（`nightreign-modding` の展開ツールを使う）。
2. me3 を入れ、専用のセーブデータで開発用プロファイルを作る。
3. パラメータだけ：Smithbox でバニラ衣装の連鎖（Goods → CharaInit → Protector → ショップ項目 + テキスト）を複製し、キャラクターの parts ファイルを新しいモデル番号でコピーして、ゲーム内の衣装棚に新しい項目が出るまで進める。
4. テクスチャだけ（必ずそのコピーで。バニラのファイルは触らない）：WitchyBND で展開し、色を変えて再パックする。
5. メッシュ：Blender でリグとウェイトを覚え、キャラクターのバニラ骨格にバインドして FLVER に書き出す。
6. 表情、物理、プラグインは最後に。いちばん手間がかかる部分です。

スクリプトを実行できるエージェント（このスキルを入れた Claude Code）なら、各段階は一つの依頼で済みます。スキルは、何かをインストールする前にどんな証拠をあなたに見せるべきかをエージェントに指示します。

## 厳守ルール：発売済みのゲームのみ

スキルは必須の **Step 0** から始まります。他のゲームからモデル、テクスチャ、モーション、エフェクト、サウンドを移植する前に、Claude は次のことを行います。

1. ウェブ検索で、移植元のゲーム（その内容を含む DLC やアップデート）が正式に一般発売され、購入できることを確認し、根拠を記録する。
2. ゲーム、DLC、キャラクターが未発売の場合、素材がリーク、未発売ビルドのデータマイニング、ベータ版に由来する場合、または発売状況を確認できない場合は、移植を**拒否**する。
3. モデル自体の利用規約を読む。多くのキャラクターモデルは他のゲームの MOD での使用や再配布を禁じており、公開ダウンロードで‌​⁠‍‌‌​⁠‌‌​⁠​‍⁠‌​⁠​‍​⁠​​​⁠​‍​⁠‌‍​⁠​‌​⁠​‌​⁠​‍​⁠​‌​‍⁠‌‌‍​⁠​⁠​​​⁠‌‌​⁠‍‌‌‍​‌​⁠​⁠‌‍‌‍‌‍​‍きることは許可ではありません。

自分のデザインによる衣装、自分の参考画像から生成した AI ベースメッシュ（参考画像が他のゲームのキャラクターを描いたものでない場合）、ナイトレイン自身の衣装の改変は、この確認なしで構いません。参考にしたコミュニティ作品（ミーム、ファンアート）は作者のものです。クレジットを明記し、その画像を配布物に含めないでください。フォークや改変をする場合も、このルールを残してください。

## 必要なもの

- スキルに対応した **Claude Code**（Step 0 のためにウェブ検索を有効にしてください）。
- PC 版 **ELDEN RING NIGHTREIGN**（ご自身で購入したもの）。
- **me3**（0.10.1 以降）、**Smithbox**、**WitchyBND**、**Blender** 4.x、**texconv**（DirectXTex）。
- ルートに応じて：**Tripo**（アカウントとクレジット、MCP サーバーまたは CLI）と、表情を描く画像生成モデル。開いている Blender シーンをエージェントに操作させるなら **BlenderMCP**。小さなツールには **SoulsFormats** と .NET Framework の C# コンパイラ。**FLVER Editor**（ナイトレイン対応のフォーク）。PMX モデルには **mmd_tools**。補助スクリプトには Pillow と NumPy を入れた **Python** 3。マルチプレイのテストにだけ **Seamless Co-op**。

## インストール

スキルのフォルダーを Claude Code のスキルフォルダーにコピーし、Nightreign Boss Skills の `nightreign-modding` も一緒に入れてください。

```
git clone https://github.com/odulme/nightreign-skin-skills
git clone https://github.com/odulme/nightreign-boss-skills
mkdir -p ~/.claude/skills
cp -r nightreign-skin-skills/skills/nightreign-skin ~/.claude/skills/
cp -r nightreign-boss-skills/skills/nightreign-modding ~/.claude/skills/
```

- 個人スキル（すべてのプロジェクト）：`~/.claude/skills/`（Windows では `%USERPROFILE%\.claude\skills\`）。
- プロジェクトスキル（一つのプロジェクトのみ）：`<プロジェクト>/.claude/skills/`。

その後、Claude Code のセッションを新しく始めてください。ナイトレインの衣装やスキンについて尋ねると説明文からスキルが読み込まれます。名前で指定することもできます（「nightreign-skin を使って」）。ファイルは普通の Markdown なので、ガイドとしてそのまま読むこともできます。
