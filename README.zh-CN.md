# Nightreign Skin Skills

[English](README.md) | **简体中文** | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

一个 Claude Code 技能，用来为《艾尔登法环：黑夜君临》(ELDEN RING NIGHTREIGN) 制作离线服装（皮肤）MOD：从参考图或现成模型出发，做出在实际游玩中站得住的服装；还可以按需加入可切换的表情、游戏内菜单，以及能装进任意 me3 整合包的安装器。它以在游戏里验证过的做法为基础，标明哪些只做过离线测试，效果粗糙的地方也会直说。里面每一条经验，都是一套在 Blender 里好看、进了游戏就出问题的服装换来的。

> 非官方粉丝项目。与 FromSoftware、万代南梦宫（Bandai Namco）、Anthropic 均无关联，也未获其认可。

## 技能内容

| 技能 | 覆盖范围 |
|---|---|
| `nightreign-skin` | 完整的服装流水线，共十个阶段（S0-S9），每个阶段都有出口关卡：从参考图定视觉、用 Tripo 生成 AI 基础模型、在 Blender 里整理成一整块连续的身体、绑到角色原版骨架并用真实动作检查、FLVER 导出约定与各个索引表、材质与贴图通道、平面表情脸卡（以及怎样去掉旧脸残留的光晕）、独立新服装的参数链、可选的原生插件（表情切换、次级摆动、NPC 菜单、联机同步、帧时间的教训）、游戏内验收，以及「安装时合并」的发布安装器。另附第二条路线：移植现成的 PMX / FBX / VRM 模型。 |

它建立在 **`nightreign-modding`** 之上（me3 配置（profile）与加载顺序、开发版叠加包、Smithbox 与 regulation 单元格修改、WitchyBND、参数配方、隐私扫描、证据标签），这个技能发布在配套仓库 [Nightreign Boss Skills](https://github.com/odulme/nightreign-boss-skills) 里。两个都要装。

文中的结论都带证据标签（`[game-MP]`、`[game]`、`[code]`、`[data]`、`[sim]`、`[inferred]`），可以分清哪些是在游戏里亲眼看到的，哪些只是离线测试或推断。引擎相关的事实是在黑夜君临 1.3.3.0 上查到的，游戏更新后请重新核实。技能正文是英文，描述是中英双语，所以用哪种语言提问都能触发。

## 完整案例：哈基蜗

哈基蜗（Hajiwo）是复仇者的一套独立梗图服装：大脑袋、小身子，脸上印的表情会随情况变化。技能从四张梗图一路跟到发布：

1. 参考板和三视图，由制作者本人确认；
2. 一次 Tripo 多视图生成；
3. Blender 整理——第一版绑定用的是刚性「布偶分件」，进游戏后能看到断面和两层袖子，被否掉了；最终采用‌​⁠‍‌‌​⁠‌‌​⁠​‍⁠‌​⁠​‍​⁠​​​⁠​‍​⁠‌‍​⁠​‌​⁠​‌​⁠​‍​⁠​‌​‍⁠‌‌‍​⁠​⁠​​​⁠‌‌​⁠‍‌‌‍​‌​⁠​⁠‌‍‌‍‌‍​‍的是一整块连续的身体；
4. 游戏文件和独立的新服装条目，原版外观仍然可以选；
5. 在固定模板上画平面表情，再投影到脸卡上（最后共 15 张脸）；
6. 一个原生插件：按情况换脸（平时、受伤、残血、倒地、放绝招、发呆、重击），让头纱摆动，并且按设计会在联机时把每个人的选择同步给队友（完整的双机测试还没做）；
7. 由圆桌厅堂壁炉前的一个 NPC 提供的表情菜单；
8. 一个安装器，把服装合并进玩家正在用的任意 me3 整合包。

案例里也记下了被否掉的路线和踩过的坑（每帧耗时 20 毫秒的插件、引擎根本没有驱动的骨骼、me3 文件重定向导致的「整合包已更新」误报），因为时间主要花在这些地方。

另有一个较短的案例——把某个二次元游戏角色的模型移植到隐士身上——用来说明现成模型路线。它能进游戏玩，但武器握持、物理和部分材质都还粗糙，技能里如实写明。

## 新手从哪里开始

1. 先从游戏封包里解出原版文件（用 `nightreign-modding` 里的解包工具）。
2. 装好 me3，用独立存档建一个开发版配置（profile）。
3. 只改参数：在 Smithbox 里照着原版复制一套服装的参数链（Goods → CharaInit → Protector → 商店条目 + 文本），并把该角色的 parts 文件复制成一个新的模型编号，直到游戏里的衣柜出现新条目。
4. 只改贴图，而且只改这份副本（绝不改原版文件）：用 WitchyBND 解包，改颜色，再打包回去。
5. 换模型：在 Blender 里学绑骨和权重，绑到该角色的原版骨架上，导出成 FLVER。
6. 表情、物理和插件放到最后，它们最费工夫。

如果用能跑脚本的代理（装了这些技能的 Claude Code），每一步就是一句请求；技能会要求代理在安装任何东西之前，先把证据拿给你看。

## 铁律：只移植已发售的游戏

技能以强制执行的**第 0 步**开头。在从其他游戏移植任何模型、贴图、动作、特效或音效之前，Claude 必须：

1. 联网搜索核实：源游戏（或包含该内容的 DLC、更新）已经正式公开发售、可以买到，并记下证据；
2. 如果游戏、DLC 或角色尚未发售，素材来自泄露、未发布版本的数据挖掘或测试版，或者无法确认发售状态，就**拒绝**移植；
3. 阅读模型自身的使用条款——很多角色模型禁止‌​⁠‍‌‌​⁠‌‌​⁠​‍⁠‌​⁠​‍​⁠​​​⁠​‍​⁠‌‍​⁠​‌​⁠​‌​⁠​‍​⁠​‌​‍⁠‌‌‍​⁠​⁠​​​⁠‌‌​⁠‍‌‌‍​‌​⁠​⁠‌‍‌‍‌‍​‍用于其他游戏的 MOD 和二次分发，能公开下载不等于获得许可。

用自己的设计做服装、用自己的参考图生成 AI 基础模型（参考图画的是其他游戏角色时除外）、修改黑夜君临自己的服装，都不需要这项检查。用作参考的社区作品（梗图、同人图）属于原作者：要署名致谢，不要把他们的图放进发布内容。如果你 fork 或改编本技能，请保留这条规则。

## 需要什么

- 支持技能的 **Claude Code**，并开启联网搜索（第 0 步需要）。
- PC 版 **ELDEN RING NIGHTREIGN**（你自己购买的正版）。
- **me3**（0.10.1 或更新）、**Smithbox**、**WitchyBND**、**Blender** 4.x、**texconv**（DirectXTex）。
- 视路线而定：**Tripo**（账号和积分；MCP 服务或 CLI）以及画表情用的图像生成模型；想让代理操作正在打开的 Blender 场景时用 **BlenderMCP**；小工具需要 **SoulsFormats** 加 .NET Framework 的 C# 编译器；**FLVER Editor**（支持黑夜君临的分支）；PMX 模型用 **mmd_tools**；辅助脚本需要带 Pillow 和 NumPy 的 **Python** 3；只有测试联机时才需要 **Seamless Co-op**。

## 安装

把技能文件夹复制到 Claude Code 的技能目录，同时装上 Nightreign Boss Skills 里的 `nightreign-modding`：

```
git clone https://github.com/odulme/nightreign-skin-skills
git clone https://github.com/odulme/nightreign-boss-skills
mkdir -p ~/.claude/skills
cp -r nightreign-skin-skills/skills/nightreign-skin ~/.claude/skills/
cp -r nightreign-boss-skills/skills/nightreign-modding ~/.claude/skills/
```

- 个人技能（所有项目可用）：`~/.claude/skills/`（Windows 上是 `%USERPROFILE%\.claude\skills\`）。
- 项目技能（只在一个项目里用）：`<你的项目>/.claude/skills/`。

装好后新开一个 Claude Code 会话。问到黑夜君临服装或皮肤时，技能会按描述自动加载；也可以直接点名（「用 nightreign-skin」）。这些文件都是普通的 Markdown，也可以当教程直接读。
